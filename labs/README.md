## How to Submit Lab Work

1. Do **not** submit your work to this repository.
2. Keep your own coursework repository named `AI-216-<StudentID>-Fall-2026`.
3. Place each lab under `labs/weekNN/` in your repository.
4. Commit regularly with meaningful messages.
5. Push your work before the deadline announced on LMS.
6. Be prepared to explain any code you submit.

Full setup instructions are in [Lab 01](week01/README.md).

---

## AI-Assisted Programming

Generative AI tools may be used for learning and development unless a
particular lab or assessment prohibits them.

You remain responsible for every line of code you submit, and you must be
able to explain, modify, and debug it during evaluation. Where required,
include an AI usage log in your lab README.

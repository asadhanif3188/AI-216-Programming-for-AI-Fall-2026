Welcome to the official course repository for **AI-216 – Programming for Artificial Intelligence**
(BS Artificial Intelligence).

## Course Goals

By the end of this course, students will be able to:
- Write clean, structured Python code
- Use Python for data handling and analysis
- Apply basic machine learning algorithms
- Follow professional workflows using GitHub
- Communicate technical learning clearly

**Fall 2026**

## Course Theme

**Programming for AI: An AI Engineering Foundation**

This course focuses not only on writing Python programs and training models, but on learning how to build AI applications that are structured, reproducible, testable, and usable by others.

## Course Goals

By the end of this course, students should be able to:

- Write clean, structured, and modular Python code for AI applications
- Acquire, preprocess, analyze, and visualize data using Python
- Build and evaluate reproducible machine-learning workflows
- Organize AI projects using professional software engineering practices
- Use Git and GitHub for version control and collaborative development
- Convert experimental notebooks into structured Python projects
- Expose AI models through REST APIs
- Package AI applications using containers
- Build small applications using foundation-model APIs
- Understand the fundamentals of embeddings and retrieval-augmented generation
- Explain and defend the engineering decisions behind their work

↓

The goal is to move from **"I can train a model"** to:

## How Students Should Use This Repository

1. **Do not submit your work directly to this repository**
2. Fork or clone the course repository
3. Maintain your own GitHub repository for course work
4. Follow the required folder structure
5. Push code regularly using meaningful commit messages
6. Use branches and pull requests when instructed
7. Keep your README and documentation updated
8. Be prepared to explain any code you submit

## GitHub & Professional Practice

This course emphasizes professional engineering habits, including:

- Version control
- Meaningful commits
- Branch-based development
- Pull requests
- Code documentation
- Reproducible environments
- Clean project structure
- Testing and debugging
- Technical communication

Students are expected to maintain a clean and professional GitHub repository throughout the semester.

---

## AI-Assisted Programming

Students may use generative AI and coding assistants as learning and development tools unless explicitly prohibited for a particular assessment.

However:

- You are responsible for every line of code you submit
- You must understand and be able to explain your solution
- You may be asked to modify or debug your code during evaluation
- AI-generated code should be tested and verified before submission
- Direct submission of generated work without understanding is not considered evidence of learning

When required, students should briefly disclose how AI tools were used in their work.

---

## Academic Integrity

- This repository is provided for learning and reference
- Direct copying without understanding is not permitted
- Students may be asked to explain, modify, or reproduce submitted work
- Collaboration is encouraged where explicitly allowed
- Assessment-specific rules take priority over general course guidelines
